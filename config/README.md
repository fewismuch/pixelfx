# 特效配置

预览页点击“保存配置”后，使用本地 `tools/serve.mjs` 将该特效的参数写入 `fx/<分类>/<名称>.json`，同时保留浏览器缓存。文件包含 `opts`、`flip`、`bg`（背景）、`actor`（角色）、`usePlayer`（自定义玩家）、`trim`（导出裁剪）、实际 `duration` 和 `updatedAt`。实际时长由服务端使用相同的 `effectDuration` 计算，不相信浏览器提交的时长。

详细预览优先读取项目文件；没有文件时沿用原浏览器配置。原有浏览器配置不会自动上传，在原浏览器中再点一次保存即可写入项目。不跨浏览器猜测或覆盖用户配置。

“恢复默认”会将项目文件写为默认参数，并清理当前浏览器对应缓存；保留默认文件，防止其他浏览器的旧缓存再次成为生效配置。项目保存失败时页面会明确显示，不能把“仅浏览器已保存”当成保存到项目成功。

音效生成默认读取这些参数，并重新计算实际时长，不使用旧的 duration 缓存。生成时会在音效清单记录所用参数和时长。临时传入的生成 options 按字段覆盖项目参数。

```sh
node tools/show-fx-config.mjs fire/meteor-impact
```

该命令只查看当前生成音效将使用的配置和时长，不调用音效服务。时序分析也必须使用同一份参数：`tempo` 会缩放阶段时间，粒子寿命等参数可能改变余响时长。保存配置不自动重生成或处理现有音频。

这里同时保存特效参数、背景和 show 中的 mirror、player、character/body、trim 开关；sprite sheet 是导出动作，不是可保存状态。预览的 0.25×/0.5× 观看速度和 fps 仍是预览控制，不作为技能固有时长写入配置。背景和 show 开关不改变音效生成的技能时长。
